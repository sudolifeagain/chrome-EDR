# 市場調査: ブラウザEDRの競合と、うちの戦い方

調査日: 2026-08-26。価格・出来事は各社公式ページ、報道、AWS Marketplace等の公開情報に基づく。推定値には(推定)を付けた。

## 要点

- ブラウザセキュリティ市場は買収ラッシュの真っ最中。2023年末から26年前半の間に、Talon→Palo Alto($625M)、Seraphic→CrowdStrike(約$400M・報道)、SquareX→Zscaler(非公開)、LayerX→Akamai($205M)、Koi/ExtensionTotal→Palo Alto(約$400M・報道)が立て続けに起きた。買われたのはいずれも「既存ブラウザに拡張やエージェントを入れる」型で、置き換え型ブラウザではない。うちのアーキテクチャ選択は買い手側の判断と一致している。
- 調査した13製品は全てクローズドなSaaSで、セルフホストできるものはひとつもない。OSSのブラウザEDRはGitHub上にも実質存在しない(最大でも65 starの攻撃ツール)。この空白がうちの主戦場になる。
- 拡張型の実勢価格は月$5〜8/ユーザーに収束している。Push Security $5、Chrome Enterprise Premium $6、Keep Aware 約$6。Googleが$6という基準価格を作った。
- 日本のセキュリティ市場は1.67兆円(JNSA・FY2024、前年比+13.8%)。国内の「セキュアブラウザ」はBYODリモートアクセス用の閉じたブラウザアプリ(CACHATTO、HENNGE等)ばかりで、拡張型の検知・対応をやる国産プレイヤーは見つからなかった。

## 市場の動き

Gartnerは2025年4月のプレスリリースで、セキュアエンタープライズブラウザの採用企業は現在10%未満、2028年に25%になると予測した(gartner.com)。2023年のレポートでは2030年にはブラウザが業務のコアプラットフォームになるとも書いている。市場規模の推計は調査会社によって$2B〜6B(2024-25年)とばらつきが大きく、TAMの数字より買収価格と資金調達の実績を信じたほうがいい。

資金調達も続いている。Islandは2025年3月に$250Mを調達して評価額$4.8B、累計$730M。LayerXは累計$45M、Pushは$49M、SquareXは$26M。いずれも2025年に調達し、うち2社はその1年以内に買収された。

## 隣接領域の価格と、ブラウザの死角

既存EDRの定価は端末あたり年$60〜185(CrowdStrike Falcon Go $59.99〜Enterprise $184.99、SentinelOne Core $69.99〜Complete $179.99)。MicrosoftはDefender for Endpoint P2を$5.20/u/月で出して下値を作っている。ただしEDRはOSプロセスを見る道具で、ブラウザの中は見えない。コンテンツスクリプトがフォーム入力を読んで外に送っても、OSレベルでは普通のブラウジングと区別がつかない。

SASE/SWG側(Zscaler 推定$72〜325/u/年、Netskope 推定$12〜18/u/月、Cloudflare Zero Trust $7/u/月)はプロキシからトラフィックを見るが、企業の暗号化トラフィックの6割超は復号されないままという調査があり(packetpushers.net)、ページ内で起きること(AiTMの偽ログイン画面、拡張の挙動)は見えない。ZscalerがSquareXを買ったのは、この死角を自認した動きと読める。

拡張機能リスク管理の専業(Secure Annex 年$5,000〜、Koi、Spin.AI)も2025-26年にほぼ全て買収済み。無料で使えたCRXcavatorはCiscoが黙って止めた。無料圏の受け皿が空いている。

## 裏付けになる脅威データ

- AiTMフィッシングは前年比146%増(Microsoft)。Tycoon 2FAだけで7.7万アカウント侵害(Group-IB)
- 2024年12月、Cyberhaven社の拡張機能がフィッシング経由で乗っ取られ、計35本前後・260万ユーザー規模の拡張サプライチェーン攻撃に発展(forbes.com等)。拡張の監査可能性が企業の調達要件になった
- インフォスティーラーのログに載った非管理端末の46%に企業認証情報が含まれ、ランサム被害企業の54%は事前に認証情報が流出していた(Verizon DBIR 2025)
- 生成AIへのデータ流出は実害が出ている。Samsungは解禁20日で3件の漏えいを起こして全面禁止にした。Ciscoの調査では27%の組織が生成AIを一時禁止、48%が非公開データを入れた経験を認めている

シャドーAI、拡張サプライチェーン、セッション窃取。どれもブラウザの中でしか見えず、どれも直近2年で企業の予算項目になった。うちのMVPが最初にシャドーAI検知を積んだのはこの並びに合わせている。

## 日本市場

国内の情報セキュリティ市場は1兆6,665億円(JNSA・FY2024、前年比+13.8%)。一方で国内の「セキュアブラウザ」と呼ばれる製品群(CACHATTO、HENNGE Secure Browser、Soliton、i-FILTER)は、BYOD端末から社内データを見るための閉じたブラウザアプリであって、検知・対応の道具ではない。拡張型ブラウザEDRの国産プレイヤーは調査の範囲では見つからなかった。海外勢はMacnica経由のIslandのように代理店で入ってくる。

セルフホスト需要は日本では特に強い。経済安保やデータ主権の文脈でオンプレ回帰が起きており、政府調達はガバメントクラウドかISMAP登録サービスが前提になる。SaaSしかない海外勢はここで詰まる。自組織のCloudflareアカウント(あるいは将来的に他基盤)に置けるOSSなら、調達の壁を回避できる。

MV3の完全移行(2025年7月にMV2廃止完了)は追い風でもある。リモートコード実行が禁止されたため、ストア審査済みコード+OSSで中身が読めることは、Cyberhaven事件後の「その拡張自体を信用できるのか」という問いへの一番説得力のある答えになる。

## うちの戦い方

差別化の軸は3つで足りる。

1. **OSS+セルフホスト**。13製品の誰もやっていない。買収ラッシュで独立ベンダーが消えていく市場では「買収されてもコードは残る」こと自体が売りになる。CRXcavator停止で無料ツールの脆さを経験した層、テレメトリを外に出せない規制業種、日本の公共隣接がターゲット。
2. **セキュリティ非専門者向けのわかりやすさ**。既存製品はSOCアナリスト向けに作られている。アラートに「何が起きた・なぜ危険・次にすべきこと」を平易な日本語で必ず付け、信号機式のダッシュボードで出す設計は、専任セキュリティ担当のいない中小・情シス1人会社に刺さる。Pushでさえ「アラートに文脈がない」とレビューで書かれている。
3. **いま問題になっている脅威から実装する**。シャドーAI(利用可視化+大量ペースト検知)、危険な拡張のインストール検知、ルックアライクドメイン。EDRの網羅性ではなく、経営者が新聞で読んだ脅威に最短で答える。

価格はGoogleの$6/u/月の傘の下に入る。セルフホストは無料(自分のCloudflare費用のみ、1,000端末で月$10程度)、マネージド版を$2〜4/u/月、SSO/SCIM/長期保存/マネージド検知ルールをエンタープライズ課金にする。WazuhやFleetが実証済みのOSS収益モデルをブラウザ層に持ち込む形になる。

リスクも書いておく。ブラウザセキュリティがFalconやZscalerのバンドル機能に埋まっていく可能性が一番大きい。独立系として生き残ったのはPush($5の透明価格+セルフサーブ)で、うちはそこにOSSを足した形で差を作る。MV3の制約で深いネットワーク遮断はできないが、これは競合も同じ条件になった。拡張を消せば見えなくなる問題は、Chrome EnterpriseのExtensionInstallForcelistでの強制配布とセットで売ることで抑える。
