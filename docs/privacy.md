# プライバシーポリシー（chrome-EDR Agent）

最終更新: 2026-08-26

chrome-EDR Agent は、企業が自組織のブラウザ利用を保護するためのオープンソースEDRエージェントです。導入は雇用主（またはシステム管理者）の判断で行われ、収集データは**雇用主が管理するCloudflareアカウント**（セルフホスト環境）に送信されます。開発元が利用者のデータを受け取ることはありません。

## 収集するデータ

| データ | 内容 | 目的 |
|---|---|---|
| 閲覧イベント | 訪問したページのURLとホスト名、時刻 | フィッシング等の脅威検知、監査 |
| ダウンロード | ファイル名・取得元URL・MIMEタイプ | 不審なダウンロードの検知 |
| 拡張機能の変化 | インストール/削除/有効化された拡張の名前・ID・要求パーミッション | 危険な拡張の検知 |
| 生成AIサイトの利用 | 対象サイトへの訪問と、**貼り付けた文字数のみ** | シャドーAIの可視化、情報漏えい兆候の検知 |
| 端末識別子 | 拡張が生成するランダムなUUIDとエージェントversion | 端末単位の集計 |

## 収集しないデータ

- ページの本文・スクリーンショット・フォーム入力値
- **貼り付けた内容そのもの**（文字数だけを記録します）
- キーストローク、パスワード、Cookie、認証情報
- 氏名・メールアドレス等の個人プロフィール（端末IDはランダム生成で、個人と直接結びつきません）

## データの送信先と保管

- 送信先は管理者が設定したエンドポイント（雇用主自身のCloudflareアカウント上のWorkers/D1）のみです。開発元のサーバというものは存在しません
- 送信はHTTPSで暗号化され、テナントAPIキーで認証されます
- 保持期間は管理者の運用に依ります（推奨アーキテクチャでは90日）

## 第三者提供・販売

行いません。ソースコードは公開されており（MIT License）、動作は誰でも検証できます。

## 利用者の選択

- 拡張の無効化・削除はChromeの拡張機能管理からいつでも行えます（組織ポリシーで強制インストールされている場合は管理者にお問い合わせください）
- 収集内容に関する問い合わせは、導入した組織の管理者へお願いします
